# 🐶 Reserva Canina – Sistema de Reservas

Aplicación en Java que permite gestionar reservas de espacios en un parque canino.

## 🚀 Funcionalidades
- Registrar reservas
- Consultar disponibilidad
- Cancelar reservas

## 🛠️ Tecnologías
- Java
- Programación Orientada a Objetos

## ▶️ Ejecución
Ejecutar la clase principal desde el IDE.
