# 🐶 Reserva Canina – Sistema de Reservas

<img width="1656" height="1001" alt="Proyecto Reserva Canina" src="https://github.com/user-attachments/assets/7d219f66-1036-425b-9fef-d6b79cf55e05" />


Aplicación desarrollada en **Java** que permite gestionar reservas de espacios para mascotas en un parque canino. El sistema está construido aplicando **Programación Orientada a Objetos (POO)** y no utiliza base de datos, ya que la persistencia se maneja mediante **serialización de datos**.

---

## 🚀 Funcionalidades

* ✅ Crear reservas
* ✏️ Modificar reservas
* ❌ Eliminar reservas
* 🔍 Consultar reservas
* 💾 Serializar datos
* 📂 Deserializar datos

---

## 🖥️ Características

* Interfaz gráfica desarrollada con **JavaFX**
* Calendario para selección de fechas
* Gestión de sedes
* Asociación de mascotas a reservas
* Visualización de reservas en tabla

---

## 🛠️ Tecnologías

* ☕ Java
* 🎨 JavaFX
* 🧠 Programación Orientada a Objetos (POO)
* 💾 Serialización de objetos
